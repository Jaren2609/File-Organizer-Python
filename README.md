# File Organizer Python

A simple and efficient Python script designed to declutter your workspace. It automatically sorts files into organized folders based on their file extensions, saving time and keeping your directories tidy.

## Features
- **Smart Categorization:** Automatically groups files into categories (Images, Documents, Archives, etc.).
- **User-Friendly:** Simple command-line interface to select the target directory.
- **Efficient:** Uses standard libraries, requiring no external dependencies.

## Prerequisites
- Python 3.x installed on your system.

## How to use
1. Clone this repository to your local machine.
2. Run the script using the command:
   ```bash
   python main.py
